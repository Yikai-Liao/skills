# 系统边界与失败契约

结构建议须对应真实压力、工作流契约及状态/规则权威，比较新增失败成本与更简单候选，给出验证或撤回条件。“读多、数据大、高可用”不能直接推导组件；只处理当前系统相关的边界。

## 从逻辑模块到部署单元

同进程、同一制品分角色启动和独立部署分别比较，不把源码隔离直接变成服务隔离。自治收益须支付通信、版本和恢复成本；共同内存、本地事务、低延迟或大中间数据可能支持共置。

流水线阶段应各有转换知识；仅按时间拆开却重复解释格式，应重组。管线拥有顺序、取消、背压和中间产物生命周期。

API 聚合跟随规则权威：领域共同规则与客户端展示差异不要混为一处；网关、BFF 或联邦本身不是结论。

## 异步任务与事件

异步接口覆盖任务身份、幂等提交、状态查询/通知、取消、结果权限与保留期。受理必须可靠交接调度，不能返回 202 后静默丢任务；明确受理、执行、结果可见与最终失败，未知总量不伪造进度。

取消请求不等于已取消；由唯一状态机裁决取消与完成，迟到消息不让终态倒退。按风险检查未调度、worker 崩溃、重复提交、取消竞态与离线恢复窗口。

队列分配工作与日志独立消费/重放不是同一契约；二者都需容量、积压/过期、毒消息及恢复责任，扩消费者不能突破下游容量。发布订阅仍耦合事件语义，须明确 schema 权威、兼容、分区顺序、保留期和重复/迟到/重放副作用，不能仅靠广播维护同步不变量。

编排与协同按流程规则归属及失败恢复选择。本地事务足够时不为未来服务化建 Saga；确需跨事务补偿时接受中间状态，明确补偿失败、对账或人工恢复。补偿是新操作，不是撤销已发生的外部效果。

## 外部副作用与未知结果

消息交付保证不自动覆盖第三方效果。可重试外部写入在调用前持久记录业务操作 ID、幂等键、请求摘要和状态；恢复时查询或沿原身份重放，不换键盲重试。

区分确定成功、确定拒绝/未执行与结果未知。未知结果查询外部权威，无法判定则对账或人工处置；不能证明重放窗口仍在下游幂等保留期内时，停止自动重试。

本地终态与待发布结果可靠提交后才确认输入；发布可重复，消费者仍需幂等。按风险检验外调前、外部已执行但响应未达、响应已达但本地未提交、提交后未发布/确认四个窗口，看内部状态与外部效果能否收敛。

## 多份状态

先定权威及写入规则；派生表示不等于多个独立权威，多个独立可写权威则需显式协调。一致性落实到写后可见、会话不倒退、最大陈旧度和失败中间态，“最终一致”不保证有界收敛。

| 候选 | 必须成立的边界与反证 |
|---|---|
| 缓存/预计算 | 有复用、成本、配额或离线压力；性能理由需基线。明确填充/失效、陈旧度、并发 miss、冷启动和源站保护；离线副本还需冲突/同步，不能当可丢缓存 |
| 读副本 | 按业务新鲜度路由；写后读回主库或等追平，计入延迟和回退负载，不把所有 SELECT 一律分流 |
| 分片 | 单节点容量或隔离确有约束，更简单调整不足；用真实键分布检查热点、局部性、跨片事务、路由权威及重分片恢复，慢查询不证明需要分片 |
| CQRS/投影 | 读写形状确有差异，派生方向、落后检测和重建明确；不必双数据库或事件溯源 |
| 事件溯源/CDC | 历史重放或渐进同步有实际需要；前者以业务事件为权威，后者仍以原状态库为权威。日志存在不证明它是事实源，历史 schema 和副作用重放须可控 |

调用者需遵守的版本、锁或租约属于契约，过期持有者必须被阻止写入。验证相关失效、落后、冲突与重建；无收益的第二份状态可撤销，这些模式不是成熟度等级。

## 故障、容量与交付

重试分类与预算见[错误处理边界](reduce-exception-surface.md)，这里检查跨边界放大：

- 队列有界且能向生产者背压，资源隔离覆盖真实共享资源；熔断、降载和回退不伪造成功。
- 可用性取决于故障域、共享数据库/身份/控制面与切换证据，不是节点数。探测超时只代表怀疑失效，切换还须阻止旧主写入。
- API、worker、初始化或迁移只在启动、权限、扩缩或故障责任的收益足够时拆分；可选依赖不应让 readiness 成为全局失败开关。
- 发布考虑新旧协议/schema 共存、容量、流量证据及撤回速度；影子流量隔离真实副作用，应用回退不代替数据恢复。
- 恢复时间与数据丢失容忍需要备份、切换或重建演练支持，不由拓扑名称保证。

选择能检验当前责任的局部故障或迁移演练，不默认建整套 SRE、压测或发布平台。
