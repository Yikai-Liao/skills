# 有证据的发现与读者验证

## 发现准入

一个可理解性问题需要同时给出：

1. **读者**：谁在读，合理的已有知识是什么。
2. **任务**：读者此刻要理解、找到、决定、执行或修改什么。
3. **位置**：准确引用、章节/段落、文件/符号，必要时给出多个依赖位置。
4. **额外操作**：需要猜哪个指代、回查哪项条件、维持哪些未说明的关系，或解压哪个表达。
5. **可避免性与后果**：为什么不是必要推导、领域复杂性或有意阅读体验；造成什么误判、遗漏、操作失败或额外搜索。
6. **最小修复与保真检查**：具体怎么改，去掉什么负担，保留什么含义，以及怎样验证。

没有实际读者观察时，影响应写成有依据的分析或预测，不伪称“读者测试表明”。拿不准就列为待确认项；仅有个人偏好时不进入问题清单。

## 轻量输出

审查结果单独交付，不混入被审查作品；用户要求的审查报告本身应包含问题、依据和建议。例如：

> **位置与问题**：`指南 / 配置缓存 / 第 2 步` 写“启用它后重启”，前一句同时介绍本地缓存和共享缓存。首次部署者无法判断重启要求适用于本地缓存、共享缓存，还是两者。建议确认后写出重启要求适用的缓存名称，不代选作者原意。验证：让读者仅凭本节分别说明启用两种缓存后是否需要重启，并与确认后的规则核对。

不必为每项输出六列大表，但六项依据必须齐全。无法确定正确改法时给出候选含义与最小确认问题，不编一个顺口的答案。

如需排序，优先处理会改变判断、掩盖风险或导致错误操作的阻塞；其次处理妨碍完成主要任务的跳转与缺失关系；最后才是局部减负。不要把风格偏好标成高严重度。

同一根因多处出现时合并并提供代表位置，避免逐句重复报告。用户要求行内批注时才使用适合格式的注释机制，保留作者原有批注。

## 应报告与不应报告

| 观察 | 裁决 |
|---|---|
| “函数有 60 行”“句子超过 30 字” | 只有度量，没有读者影响，不成立 |
| 专家指南直接使用该领域标准术语 | 不能因外行不熟悉就报 jargon 问题 |
| 本章有意延迟揭示人物身份 | 若符合叙事目标，保留悬念，不强制结论先行 |
| 删除操作之前没有说明会同时删除共享副本，提示藏在末尾 | 操作者在不可逆动作前缺少关键条件，成立 |
| 摘要写“方案有效”，限制部分才写仅在特定样本成立 | 决策读者可能误用适用范围，成立 |
| 报告用“为避免过度宣称，这里保留了限制”解说写作策略 | 改为直接陈述具体限制；保留对结论适用性的影响 |
| 把 `task` 和 `job` 统一能减少名词 | 先确认是否同一对象；语义不同则不合并 |
| 流程被多层 helper 分开 | 仅当契约不足、真实任务必须追踪额外关系时成立 |
| 函数是只读名称却会刷新令牌，调用者无法从契约获知 | 补行为契约或在权限内改名；不能为了名字删掉刷新行为 |

事实错误、软件缺陷和可理解性可以同时存在。分别注明类别：事实核查需要证据，行为缺陷需要复现或契约依据；不能用“读起来费力”替代这些证明。

### 一条原话记录，不等于一个已证实的问题

一张公开的用户研究便签记录了原话：

> I don't think it is a problem, I just can't count.

便签另标有参与者编号 5。任务是决定这条材料能支持怎样的发现。

反例报告：“五名用户因界面难懂而计算失败，应简化页面。”它把编号当成样本数量，把个人表述改成已观察到的失败，又把原因归给了未提供的界面。

正面处理：

- **原始记录**：保留原话及参与者编号 5；两者应能对应原记录。
- **证据缺口**：这张便签没有给出具体任务、操作位置、行为结果或其他参与者情况。
- **当前裁决**：不足以认定一个可理解性问题，也不能据此否定存在问题。
- **下一步**：回查对应任务和记录，确认参与者当时在数什么、界面提供了哪些线索，以及哪里发生误解，再决定是否报告及如何修复。

分析与改动建议可以建立在观察之上，但不能混写成观察事实。原话不完整时保留具体缺口，不用一段看似完整的 finding 掩盖缺证；也不必为每条无关记录开启新调查。

## 验证方法

开始前选少量代表性任务，不让所有产物都完成同一套测试：

- **定位**：读者从目录或入口找到一个条件、参数或结论。
- **复述**：读者用自己的话解释对象关系、机制、论点及适用边界。
- **使用**：读者根据文档完成步骤或作出有条件的判断。
- **预测**：维护者预测一个输入的结果、错误路径或局部修改的影响。
- **体验**：叙事读者能跟上视角和事件，同时保留作者有意设置的悬念。

每次记录任务、参与者/模拟方式、材料版本、观察到的卡点、结果和未覆盖部分。可比较理解正确率、查找路径、需要求助的位置和耗时，但不虚构数字或跨体裁总分。

实际比较改写前后时，尽量保持任务和信息量一致，降低读者已经见过答案带来的学习效应。模型或作者自查适合发现明显问题，不能据此声称真实人群理解时间下降。

完成条件：所选任务可完成；必须保留的语义已核对；重要未解决项已说明。允许“本范围未发现有充分证据的问题”，不要求每个维度都有 finding。
